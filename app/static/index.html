What could this release break?

Pick two git tags. PreFlight reads every change between them and returns a readiness report: risk score, breaking API changes, coverage gaps, config mismatches, release notes and a rollback plan.

Release range
Runs locally in well under a second · nothing leaves the server
How it works

Diff engine

Classifies every changed file as breaking, risky or safe, using Python AST comparison.

Coverage mapper

Finds new public functions that no test calls, and generates a stub test for each gap.

Sentinel

Catches migrations with no code, undocumented env vars and breaking API responses.

Drafter

Writes release notes, a fix-before-release list and an ordered rollback plan.
